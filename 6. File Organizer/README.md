# File Organizer

A Python command-line application that automatically organizes files into folders based on their file extensions.

## Features

- Organizes files automatically
- Supports multiple file categories
- Creates folders automatically
- Handles unknown file types
- Prevents duplicate filenames from being overwritten
- Displays moved files
- Displays a summary after organization
- Handles invalid folder paths
- Handles permission errors
- Simple command-line interface

## Supported Categories

The application supports categories such as:

- Images
- Documents
- Spreadsheets
- Presentations
- Videos
- Music
- Archives
- Python
- Code
- Executables
- Others

## Technologies Used

- Python 3
- os module
- shutil module

## Requirements

Python 3.x must be installed on your system.

No external Python packages are required.
