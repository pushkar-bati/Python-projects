# Library Management System

A simple console-based Library Management System built using Python.

## Features

- Add books
- View all books
- Search books by title or author
- Add library members
- View members
- Issue books
- Return books
- View currently issued books
- Store data using JSON files
- Prevent issuing an already issued book
- Prevent duplicate member emails

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists
- Dictionaries
- Exception Handling
- Date and Time
