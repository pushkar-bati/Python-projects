# Password Manager

A Python command-line password manager that allows users to securely manage passwords and generate strong random passwords.

## Features

- Add passwords
- View saved passwords
- Search passwords by website
- Delete passwords
- Generate strong random passwords
- Store data in JSON format
- Handle invalid input
- Handle corrupted JSON files
- Prevent password data from being committed to GitHub

## Technologies Used

- Python 3
- JSON
- `secrets`
- `string`
- `os`

## Requirements

Python 3.x

No external Python packages are required.
